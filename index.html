طرق كتابة كود JavaScript

1. وحدة التحكم (Console)

كتابة وتنفيذ أوامر مباشرة في Console المتصفح — مناسبة للاختبارات السريعة.

2. Node.js

بيئة تشغيل JavaScript على Server-side، تكتب الكود في ملف .js وتشغّله بـ Node.js.

3. وسم Script

كتابة الكود داخل <script> في صفحة HTML (داخل head أو body).

4. ملف خارجي (External)

كتابة الكود في ملف منفصل وربطه بـ src — الأفضل للمشاريع الكبيرة.

<script src="./script.js"></script>
// الكود الموجود داخل script.js هو من سيتم تنفيذه

🔑 تسمية المتغيرات (Naming Convention)
  • كلمة واحدة: حروف صغيرة — مثل age.

Strings

السلسلة النصية (String) هي أحرف أو أرقام أو رموز بين علامتي تنصيص: ' ' أو " " أو ` ` (backticks).

ConcatenationInterpolation
دمج نصوص باستخدام +تضمين قيم داخل backticks بصيغة ${...}
// Concatenation
const fullName = firstName + ' ' + lastName;

// Interpolation
const fullName = `${firstName} ${lastName}`;

// سلسلة متعددة الأسطر
const message = `line one
line two`;

Boolean · null · undefined

Boolean يمثّل قيمتين فقط: true أو false، ويُستخدم لاتخاذ القرارات.

null

تعني عدم وجود قيمة — تم تعيينها عمدًا كـ "فارغة".

undefined

تعني أن المتغيّر لم تُعيَّن له قيمة بعد، أو غير معرّف أصلًا.

const name = null;      // متغيّر ليس له قيمة عمدًا
let age;               // متغيّر لم يُعيَّن له قيمة بعد
console.log(age);     // undefined

Object · Array

Object

مجموعة من الخصائص (Properties)، كل خاصية هي زوج Key:Value — يشبه Dictionary في بايثون.

Array

شكل من أشكال الـ Object، لتخزين مجموعة قيم مرتبة بترقيم (Index) يبدأ من صفر.

const userData = {
  name: "Ali",
  gender: "Male",
  age: 23
};

const numbers = [1, 2, 3, 4, 5];

أساسيات الدوال (Functions)

الدالة (Function) هي مجموعة أوامر تنفّذ وظيفة محددة عند استدعائها، تساعد على تنظيم الكود وإعادة استخدامه.

Custom Functions

دوال ينشئها المبرمج بنفسه لتنفيذ وظيفة معينة.

Built-in Functions

دوال جاهزة في اللغة مثل parseInt() و Math.max().

تتكوّن الدالة من: اسم، معاملات (Parameters)، جسم الدالة (Function body)، وجملة الإرجاع (return).

function calculateArea(length, width) {
  let area = length * width;
  return area;
}
console.log(calculateArea(5, 10)); // 50

// معامل بقيمة افتراضية (Default Parameter)
function getUserName(name = "Ali") {
  console.log("Hello, " + name);
}
getUserName();           // Hello, Ali
getUserName("Mohamed");  // Hello, Mohamed

طرق تعريف الدوال

function multiply(a, b) {
  return a * b;
}
const multiply = function(a, b) {
  return a * b;
};
const multiply = (a, b) => a * b;

بالإضافة إلى ذلك:

  • IIFE (Immediately Invoked Function Expression): دالة تُعرَّف وتُستدعى فورًا دون تخزينها في متغيّر: (function(a,b){ console.log(a*b); })(5,6);
  • Methods: دوال معرّفة داخل كائن (Object) — مثل person.sayHello().
  • Callback function: دالة تُمرَّر كـ Argument إلى دالة أخرى لتُستدعى عند حدوث حدث معيّن، مثل setTimeout(add, 2000).

Scope

الـ Scope يحدّد من أين يمكن الوصول إلى متغيّر أو دالة في الكود:

Global Scope

متغيّر مُعرَّف خارج أي دالة — يمكن الوصول إليه من أي مكان في الكود.

Function Scope

متغيّر مُعرَّف داخل دالة — لا يُرى إلا داخلها فقط.

Block Scope

متغيّر let/const داخل كتلة (مثل if أو for) — مرئي فقط داخل تلك الكتلة.

Scope Lookup

عند البحث عن متغيّر، يبحث الكود في النطاق الحالي أولًا، ثم ينتقل للأعلى تدريجيًا حتى يجده.

Hoisting

الـ Hoisting هو رفع تعريفات المتغيّرات والدوال إلى أعلى نطاقها قبل تنفيذ الكود — لكن التفاصيل تختلف حسب الكلمة المستخدمة:

  • var: تُرفع، وقيمتها undefined حتى تصل للسطر الذي يعرّفها.
  • let / const: لا يعمل معها Hoisting — استخدامها قبل تعريفها يسبب ReferenceError.
  • الدوال العادية (function): تُرفع بالكامل، فيمكن استدعاؤها قبل تعريفها في الكود. (لا يعمل هذا مع Arrow Functions.)

Attributes

Built-in Attributes

سمات مضمّنة في عناصر HTML، مثل src في <img>، و id، و class.

Custom Data Attributes

سمات تُنشئها أنت بنفسك لتخزين بيانات إضافية، بصيغة data-attributeName.

<h1 id="myElement" data-name="HTML">HTML</h1>

// الوصول إليه عبر الـ Custom Data Attribute:
const element = document.querySelector('[data-name="HTML"]');
